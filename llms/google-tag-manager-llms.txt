# Google Tag Manager

> Google Tag Manager (GTM) is a tag management system that lets you deploy and update measurement codes and related code fragments (tags) on a website or mobile app without editing site code. The Tag Manager API v2 provides programmatic management of accounts, containers, workspaces, tags, triggers, variables, versions, and user permissions across web, mobile, and server-side containers.

## APIs

- [Google Tag Manager API v2](https://developers.google.com/tag-platform/tag-manager/api/v2): Access and modify container and tag configuration. Base URL https://tagmanager.googleapis.com
- [Google Tag Manager Server-side Tagging API](https://developers.google.com/tag-platform/tag-manager/server-side): Build custom tags, clients, and variables that run in a server-side container.
