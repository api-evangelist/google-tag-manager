# Google Tag Manager

> Google Tag Manager (GTM) is a tag management system that lets you deploy and update measurement codes and related code fragments (tags) on a website, mobile app, or server-side container without editing site code. The Tag Manager API v2 provides programmatic management of accounts, containers, workspaces, tags, triggers, variables, container versions, and user permissions across web, iOS, Android, AMP, and server-side usage contexts.

## How this API works

- Base URL `https://tagmanager.googleapis.com`, all paths under `/tagmanager/v2`. Single production host; there is no sandbox host and no test mode.
- Auth is **OAuth 2.0 authorization code only** — no API keys. Seven scopes separate read, edit, publish, delete, and user management.
- Resources are addressed by a composite **resource path** (`accounts/{a}/containers/{c}/workspaces/{w}/tags/{t}`) returned by the previous call, not by concatenating ids.
- Writes use **fingerprint-based optimistic concurrency** (a `fingerprint` query parameter), not ETags. There is **no `Idempotency-Key`** — a retried create duplicates.
- Changes stage in a **workspace**, freeze into an immutable **container version**, then **publish** to live traffic. Publishing is the only step that changes what runs on a customer's site.
- Quota is **per Google Cloud project**: 10,000 requests/day and 0.25 QPS (25 per 100s window). Exhaustion returns **HTTP 403** (not 429) with reason `userRateLimitExceeded` or `quotaExceeded`. No rate-limit response headers are emitted.
- Errors use the **Google JSON error envelope** (`error.code` / `error.message` / `error.errors[].reason`), not RFC 9457. Branch on `errors[].reason`; Google states the message text may change at any time.

## Known absences

- No status page or incident dashboard for Tag Manager (status.cloud.google.com covers Google Cloud only and does not list it).
- No published deprecation policy for this API, and no RFC 8594 Sunset/Deprecation response headers.
- No webhooks, no event stream, no AsyncAPI — the API is configuration-only, so there is nothing to subscribe to.
- No published SLA on the free tier.
- No sandbox host, no test-mode credentials, no magic test identifiers. Every call is production, and destructive operations have "no warnings, no confirmations, and no undo."
